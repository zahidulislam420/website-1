# DevConf 2026 Landing Page 🎉

A modern, responsive landing page for **DevConf 2026** — the premier developer conference.  
This project highlights event details, speakers, pricing plans, hackathon highlights, and footer with social links in a clean and professional layout.
Website demo: https://zahidul-dev.github.io/Assignment-01/
---

## 🚀 Features
- **Navigation Bar** → Logo, menu links, and "Register Now" button
- **Hero Section** → Full-screen banner with tagline and CTA
- **Speakers Section** → Grid layout showcasing featured speakers with track labels
- **Pricing Section** → Three subscription tiers (Standard, Pro, Team) with highlighted Pro plan
- **Hackathon Highlights Section** → AI Challenge projects with hover effects and demo links
- **Footer Section** → Logo, social links, and copyright
